# Core admission and authority

Use for every core **Adapt** or **Incubate**, including execution.

Require all four:

1. **Harm:** reproduce consequential correctness, security, isolation, data-loss, deadlock, cancellation, recovery, or portability harm—not convenience or parity.
2. **Corroboration:** cite a dated public DSH report or reproduce a mature harness's testable guarantee missing in DSH; a competitor alone is insufficient.
3. **Upstream gap:** exact-lane behavior shows the public native contract is inadequate; unknown, private, inventory-only, or untested behavior proves no gap.
4. **Boundary:** define conformance, authority, containment, failure, lanes, and retirement.

Return **Native** when DSH is adequate, **Adapt** for a missing adapter, **Incubate** for the smallest removable opt-in guarantee, or **Unsupported** with evidence and no executor. Verify reuse licensing. When upstream is adequate: adopt, shim older lanes, deprecate, then remove after approved migration.

## Bind effects

A plugin or worktree is not a security boundary. Messages grant no authority; a child cannot exceed its parent. Run no arbitrary plugin, build, or live agent without a verified OS boundary.

A fixture PASS is not transferable. Launch the actual workload through the admitted provider. Bind its report to provider/policy digest, workspace, denials, environment/resources/processes, cancellation/recovery/cleanup, and result. Missing containment or uncertain cleanup stops with no fallback; claim only passing checks. For communication also test identity, integrity, replay, backpressure, crash-safe ordering/recovery, and claimed confidentiality.
