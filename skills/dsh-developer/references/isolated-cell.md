# Isolated-agent-cell admission

Use only for a separately owned child workspace plus whole-environment containment. DSH keeps ownership of subagent lifecycle, Team roster/mailbox/tasks, and orchestration.

## Run

DSH Web:

    /dsh-developer-admit-cell {"distro":"Ubuntu-22.04"}

CLI:

    node bin/dsh-developer.js admit-cell --dsh <path-to-dsh> --wsl-distro Ubuntu-22.04

The keyless gate reruns exact capability and lab conformance, executes only the installed public `childSessionMeta` behavior seam, inspects the bounded installed sandbox contract, and records dated public evidence. It never runs a model, repository, build script, or caller workload.

`--dsh` selects trusted executable input, not a sandbox subject. Review its installation provenance first. The gate requires the entry to match the public package's declared official CLI before execution, but local manifest identity is not registry-integrity proof.

## Interpret

- `Incubate`: all four core-gap conditions pass. Implement only the removable cell boundary named in the report.
- `Unsupported`: retain the report and blocker; expose no executor.
- Preview-lane admission remains preview evidence and cannot support a blocking release claim.

Do not infer that a passing lab alone admits the feature. Preserve the capability, lab, and admission digests together. The admitted guarantee is a disposable child workspace, credential-free fixed environment, no child network, resource bounds, cancellation, recovery, and verified cleanup. It excludes roster, mailbox, task board, ordinary lifecycle, and generic orchestration.

If public DSH supplies equivalent behavior, adopt it, shim older supported lanes, deprecate this incubation, then remove it after an approved migration.
