# Project logo

`logo.png` is the selected blue whale with an amber wrench, on a transparent background, used by both project READMEs.

The whale is based on [DeepSeek's official logo](https://github.com/deepseek-ai/DeepSeek-LLM/blob/main/images/logo.svg). DeepSeek branding belongs to DeepSeek. This adaptation identifies the independent dsh-developer project and does not indicate official endorsement.

The logo was edited with the built-in imagegen tool, adding a wrench behind the whale's fin and recoloring it amber for visibility on light and dark backgrounds.
